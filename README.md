# NovaEye AI Surveillance System

NovaEye is a real-time intelligent camera monitoring system developed with Python, OpenCV, PySide6 and YOLO.

## Features

- Real-time camera stream
- YOLO object detection
- Target ID display
- FPS counter
- Target counter
- Screenshot capture
- Video recording
- Live system logs
- Modern dark user interface

## Technologies Used

- Python
- OpenCV
- PySide6
- Ultralytics YOLO
- NumPy
